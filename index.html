用你的 GitHub 账号做一份私密云端存档。手机、电脑、不同浏览器粘贴同一个令牌后， 进度（掌握状态、错题、收藏、每日记录、断点）自动合并，换设备接着刷。

尚未连接。填入令牌后点击「连接并同步」。
怎么生成令牌？（约 30 秒，只需一次）
  1. 打开 github.com/settings/tokens → Generate new token (classic)
  2. Note 随便填（如 pmle-sync），Expiration 建议 90 天
  3. 权限只勾选 gist 一项，其它全部不勾
  4. 点 Generate，复制 ghp_ 开头的字符串，粘贴到上面输入框

令牌仅存于本机 localStorage，只用于读写你自己的私密 Gist；本页面不引入任何第三方统计脚本。 若担心泄露，可设 90 天过期，到期重新生成并重新连接即可，云端进度不会丢。
