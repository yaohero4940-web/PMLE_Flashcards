Not connected. Paste your token and click "Connect & sync".
How do I create a token? (~30 seconds, one-time)
  1. Open github.com/settings/tokens → Generate new token (classic)
  2. Note: anything (e.g. pmle-sync); Expiration: 90 days recommended
  3. Scope: check gist only — leave everything else unchecked
  4. Click Generate, copy the ghp_ string and paste it above

The token lives only in this browser's localStorage and is used solely to read/write your own private Gist; this page loads no third-party analytics. If you worry about leaks, set a 90-day expiration — regenerate and reconnect when it expires; your cloud progress stays intact.
