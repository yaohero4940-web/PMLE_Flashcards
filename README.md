# PMLE 闪卡 · 402 题背诵刷题

基于 Google PMLE（Professional Machine Learning Engineer）402 题答案修正版 PDF + 375 题中英对照精讲（Susan 核对修正版）构建的闪卡刷题应用。

- 纯静态网页应用：HTML + CSS + 原生 JavaScript，零依赖、零后端、零登录
- 全部进度保存在浏览器本地（localStorage），刷新 / 关闭浏览器进度不丢
- 电脑、手机自适应

## 核心功能

- **每日 20 题**：每天开场先复习"到期 / 昨日答错未掌握"的题，再开 20 道新题；刷完可"再来 20 题"
- **错题 1 分钟重弹**：答错的题约 1 分钟后再次出现，直到答对且点击「已掌握」；同一题当天答错 3 次改入"攻坚区"在轮末集中攻克
- **已掌握 / 未掌握**：答对后由你确认。已掌握 → 按 1 / 3 / 7 / 21 天遗忘曲线间隔轮回复现；未掌握 → 1 分钟后重做 + 进入明日复习队列
- **断点记忆**：任何操作实时保存，中途退出随时从断点继续
- **收藏夹**：每题可 ⭐ 收藏，收藏夹可单独刷一轮，不占每日额度
- **答案标注**：翻面后正确答案绿色标注、你选错的选项红色标注，下方依次为中文翻译与精讲
- **题库管理**：搜索 + 按状态筛选 + 查看详情；进度可导出 / 导入 JSON（换设备备份）
- **统计**：打卡热力图、连续天数、正确率、未掌握清单

## 跨设备同步（手机 / 电脑 / 不同浏览器进度一致）

进度默认只存本机浏览器（localStorage）。开启云同步后，用同一个 GitHub 令牌即可多端共用一份进度。

1. 打开 `github.com/settings/tokens` → **Generate new token (classic)**
2. 权限只勾 **gist**（其它都不勾），生成后复制 `ghp_…`
3. 打开网页 → 顶栏「同步」→ 粘贴令牌 → **连接并同步**

同步机制：

- 自动在你的 GitHub 账号下创建**私密 Gist**（`pmle-progress.json`）作为云端存档；令牌只存本机 localStorage，只用于读写你自己的 Gist
- 每台设备首次连接会**合并**：以每题最后操作时间较新的一份为准，错题统计取并集，不会互相覆盖
- 作答后约 2.5 秒自动上传；切回页面（超过 1 分钟）自动拉取；答题过程中不打断
- 安全兜底：若本次会话尚未成功拉取云端状态（断网 / 令牌失效），**不会上传**，避免旧设备把云端进度冲掉
- 想换设备：在新设备重复第 3 步即可；令牌过期只需重新生成并重新连接，云端进度保留

排查同步问题（两端进度不一致时）：

- 同步页会同时显示「本机进度：做过 X 题」和「云端存档：做过 X 题 · 云端更新于 …」，两端对不上时先看这两个数字
- 对比两端「存档」后的 8 位 ID：不一致说明令牌属于不同 GitHub 账号（各自建了各自的存档），需统一用同一账号的令牌
- 云端显示 0 题：说明有学习记录的那台设备从未上传成功——确认令牌是在「平时刷题的那个浏览器」里输入的（每个浏览器的进度相互独立），且徽章不是「同步异常」
- 云端有题而本机 0：点「立即同步」拉取合并
- 点「打开云端存档核对」可直接在浏览器里查看 gist 内容，确认云端到底有没有数据

> 提示：GitHub 令牌等同于账号的 gist 读写权限，请勿在公共电脑上保存；建议设置 90 天过期。

## 键盘快捷键（电脑端）

- `1`–`4`：选择选项（多选题为切换勾选）
- `Enter`：多选题提交 / 已掌握（翻面后）
- `M`：已掌握 · `X`：未掌握 · `S`：跳过

## 本地使用

直接用浏览器打开 `index.html` 即可（双击）。若图片不显示，用任意静态服务器启动：

```bash
cd pmle-flashcards
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 部署到 GitHub Pages

1. 在 GitHub 新建一个公开仓库（例如 `pmle-flashcards`）
2. 把本目录全部内容上传到仓库 `main` 分支（`index.html` 必须在根目录）
3. 仓库 **Settings → Pages → Build and deployment**，Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/pmle-flashcards/`

> 注意：换浏览器或清空浏览数据会丢失进度，请定期在「题库 → 导出进度」备份 JSON 文件。
