几个注意点
网址大小写敏感：仓库名是 PMLE-FLASHCARDS 之类带大写的，网址也要按原样输入。
首次部署要排队：如果打开是 404，等 2~5 分钟再刷新。可以看仓库页的 Actions 标签，里面有部署进度。
以后更新：本地改完文件后，git add . && git commit -m "更新" && git push，推送后 GitHub 会自动重新部署，几十秒后网页就更新。
如果你看到网页但样式/数据没加载：通常是引用了以 / 开头的绝对路径，改成相对路径即可（比如 href="/css/style.css" 改成 href="css/style.css"）。从你的结构看引用了 css/、js/、data/，如果遇到这个问题告诉我，我帮你批量修。
